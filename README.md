# Hoops Oracle

A college basketball game predictor using a tempo-free efficiency model (the approach behind KenPom and Bart Torvik).

- **Predict**: projected score, win probability, spread, total, fair moneyline, and edges vs sportsbook lines
- **Slate**: predict a full night of games at once, sorted by value
- **Team ratings**: paste ratings from barttorvik.com or KenPom
- **Build & backtest**: fit your own opponent-adjusted ratings from game results and test them walk-forward
- **Track record**: log predictions and grade them against final scores

The whole app is a single static `index.html` with no build step. Open it in a browser or deploy it to any static host.

For entertainment and analysis only.
